# Logos oficiales

El manual de marca prohíbe redibujar, trazar o reconstruir el logo con CSS, SVG
manual, texto o formas geométricas. Por eso esta carpeta está vacía: los archivos
tienen que venir de los originales oficiales.

Deja acá los archivos con estos nombres exactos y el componente `Marca` los toma
automáticamente:

- `adipa-logotype-full-color.svg` — sobre fondo blanco o `#F3F4FF`
- `adipa-logotype-white.svg` — sobre `#704EFD`, `#2CB7FF` o `#091E42`

Mientras no estén, la aplicación muestra solo el nombre de la herramienta en
Poppins, que no es el logotipo de marca.
